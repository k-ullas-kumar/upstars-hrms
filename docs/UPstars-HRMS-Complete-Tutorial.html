1. About this guide & how to use the demo

UPstars HRMS is a standalone multi-tenant Human Resource Management System (not linked to the recruitment CRM). The frontend is a React SPA; the backend is an Express + TypeScript modular monolith using Sequelize.

What you will learn

  • How every major screen works and who can open it
  • Complete check-in → work day → check-out flow (including the 5-second cancel shortcut)
  • How HR, managers, and admins approve leave, corrections, documents, and assets
  • How to run reports and read the audit trail

2. Getting started — sign in & workspace tour

Sign in

1
Open http://localhost:3000 — you land on the branded login screen (UPSTARS gold wordmark, navy atmosphere, soft cursor glow).
2
Enter a demo email (e.g. employee@upstars.in) and password Ullas@Intern.
3
Submit — the API returns a JWT and your roles/permissions. The app stores the token and loads the protected shell.
4
Forgot password — use /forgot-password then /reset-password when a reset token is issued (demo environments may log the link server-side).

5. End-to-end — People & organisation

5.1 Organisation setup (Admin / HR)

Example actor: admin@upstars.in or hr@upstars.in.

1
Open People → Branches. Create or edit “HQ Bangalore” (or your city office).
2
Open Departments. Ensure Engineering, HR, Sales (or your structure) exist.
3
Open Designations. Add titles such as Software Engineer, HR Manager.
4
Open Settings → Company to confirm tenant name and timezone (demo uses Asia/Kolkata).

5.2 Hire / create an employee

1
Go to People → Employees → add employee (form modal).
2
Fill employee number, full name, email, department, designation, branch, joining date, manager.
3
Save — the person appears in the directory. Open the detail page for status, contacts, and related records.
4
Bulk path: /people/employees/import — upload CSV, review mapping/errors, commit.

5.3 Onboarding checklist

1
Open People → Onboarding (needs onboarding:manage).
2
Create or open a checklist; tick items (laptop issued, policy signed, accounts created).
3
Track completion until the new joiner is marked ready for day-one attendance.

6. End-to-end — Attendance & leave

6.1 Daily check-in (Employee)

Example actor: employee@upstars.in (Ullas Kumar).

1
Sign in → open Attendance.
2
Tap the large Check in control. Optionally share location when prompted (geofence may flag outside punches).
3
Header updates live: timer shows HH:MM:SS total for today. Status flips from “Not checked in”.
4
Work normally. Timer keeps counting without refreshing the page.

6.2 Check-out shortcut (5-second cancel)

1
In the header, click Check out beside the timer.
2
A navy/gold banner appears: “Checking out in 5s”. Click Cancel if it was accidental.
3
If you let the countdown finish, the API records CHECK_OUT, the timer stops, and the shortcut hides.
4
You can also check out from the Attendance page punch control — same API, no countdown.

6.3 Corrections & approvals

1
Employee: Attendance → Corrections → request a missed punch (date, type, time, reason).
2
Manager/HR: open Approvals tab → Approve or Reject with an optional note.
3
On approve, a corrected attendance event is created and appears in history.

6.4 Team attendance (Manager)

Login as manager@upstars.in → Attendance → Team tab → pick a date → review punches for reports.

6.5 Leave request → approve

1
Employee: Leave → create request (type, from/to, reason). Balance is validated.
2
Manager/HR: Leave → Approvals → Approve/Reject.
3
HR: manage leave types and opening balances when permitted.
Geofence Admins can configure geofences under the API/settings path. Check-ins outside the fence may be flagged for review while still recorded.

7. End-to-end — Assets, teams, tasks, documents

7.1 Assets lifecycle (Asset Manager)

Actor: assets@upstars.in.

1
Open Assets → add a laptop/phone (tag, serial, category, status).
2
Assign to an employee → employee acknowledges → later mark return.
3
Track assignment history from the asset / assignment views.

7.2 Teams & tasks

1
Teams: create a team, add members (manager needs team permissions).
2
Tasks: create tasks, assign owners, move status (open → in progress → done).
3
Employees see tasks relevant to them on /tasks.

7.3 Documents

1
HR creates/maintains a document template (offer letter, experience letter, etc.).
2
Generate a document for an employee → review → approve when required → download PDF.
3
Generated documents remain listed under Documents for auditability.

8. End-to-end — Reports, settings & audit

8.1 Reports

Open Reports (needs report permissions). Pick a pack such as Attendance, Leave, or Assets; set a date range when prompted; export CSV.

8.2 Settings → Roles

Company Admin opens Settings → Roles to inspect the permission matrix. Seeded roles (COMPANY_ADMIN, HR_MANAGER, MANAGER, EMPLOYEE, ASSET_MANAGER) are the source of truth from backend role definitions.

8.3 Audit log

Open Audit to see who changed what (create/update/approve/reject). Use this after sensitive actions (role changes, corrections, document approvals).

8.4 Notifications

The header bell shows in-app notifications (approvals, assignments). Mark as read from the menu.

10. Frequently asked questions (FAQs)

Why does the header say “Not checked in” even after I punched?
Your user must be linked to an employee record (employeeId). After a product update that fixed camelCase mapping, reload once, then punch again — the timer should update live without another refresh.
Does Logout also check me out?
No. Logout only ends the session. Use the header Check out button (or the Attendance page) to close your attendance.
What is the 5-second banner for?
It protects against accidental check-out from the header shortcut. Press Cancel to stay checked in. After 5 seconds the check-out is submitted.
I don’t see Employees / Settings / Audit in the menu.
Those links are permission-gated. Sign in with a role that has the required permission (e.g. admin or HR), or ask an admin to adjust roles under Settings → Roles.
Can I use this with the Recruitment CRM?
No — UPstars HRMS is a standalone product. It is not wired to the recruitment CRM repositories.
Which database does local demo use?
SQLite by default for easy localhost setup. Production can use PostgreSQL via Sequelize configuration.
My check-in was flagged.
Location was missing, inaccurate, or outside an active geofence. The punch is still stored; managers/HR can review flagged entries and corrections.
How do I reset a demo password?
Re-run the backend seed (npm run db:seed in hrms_BE) to restore Ullas@Intern for all demo users, or use the forgot-password flow if enabled.
Where do API calls go?
Browser → /api/v1/… with Bearer JWT. Backend middleware authenticates, enforces RBAC, then hits the matching service (attendance, leave, employees, …).
Is payroll / recruitment included?
Not in this MVP. Navigation intentionally omits payroll, recruitment ATS, chat, and sales CRM.
Timezone issues on “today’s” attendance?
The app uses your browser’s local calendar day for “today” bounds so early-morning punches (e.g. IST) are not cut off by UTC midnight.
Who can approve leave and attendance corrections?
Users with leave:approve / attendance:approve — typically Manager and HR roles in the seed data.
How do notifications work?
In-app notifications are listed from the header bell. They cover events such as approvals and assignments depending on what the backend emits.
Can multiple people be checked in on one account?
Attendance is scoped to the signed-in user’s linked employee. Each person should use their own login.
Where is the official product branding?
Login and shell use the UPstars wordmark in gold on navy, subtitle “Human Resource Management System” / “HRMS Platform”, without a circular logo treatment.
